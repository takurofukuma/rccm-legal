開発者による情報収集

本アプリは、氏名・メールアドレス・位置情報・端末識別情報その他利用者を直接識別する情報を送信・収集しません。開発者が受け取るのは、下記「アプリ内課金」「AI所見」「利用状況データ」の各項に記載した情報のみです。

ネットワーク通信

本アプリは、学習進捗のiCloud同期、Apple純正のApp内課金（RevenueCat経由）、下記「AI所見」をユーザーが自ら実行した場合の通信、および下記「利用状況データ」の送信を除き、インターネット通信を行いません。広告配信・トラッキング目的の通信は一切ありません。

端末内に保存されるデータ

学習進捗（解答履歴・正解率・苦手問題の自動抽出・ブックマーク・累積解答回数）は、端末の UserDefaults / SharedPreferences に保存されます。アプリを削除すると、これらのデータも削除されます。分野ごとの進捗は分野別キー（例：study_records_v2_kasen）で管理し、将来の分野追加時にも干渉しません。

iCloud 同期

iCloud にサインインしている iOS デバイスでは、学習進捗が iCloud Key-Value Store を通じて、ユーザー自身の iCloud アカウント内に自動保存されます。これにより同じ Apple ID の他端末との進捗共有や、機種変更時の引き継ぎが可能です。

iCloud に保存されるデータはユーザー自身のアカウント管理下にあり、開発者がアクセスすることはありません。iCloud 同期を望まない場合は iOS の設定で本アプリの iCloud 利用をオフにできます。

アプリ内課金

課金は2種類です。①択一問題の解放（買切¥1,500）: 累積20回までは無料体験（3分野すべて含む）、21回目以降を解答する場面で「RCCM 3分野 全782問解放」の購入をご案内します。②AI所見の回数券（消費型・10回¥3,000・失効なし）: 記述対策のAI所見に使用します。①は1回の購入で河川砂防・道路・鋼コンの3分野すべてが解放され、追加の課金はありません。②は使いたい場合のみの任意購入です。月額・年額のサブスクリプションはどちらにもありません。決済・購入検証は Apple の App Store / StoreKit（iOS版）および Google Play / Google Play Billing（Android版）が行い、購入履歴の管理・購入状態の確認・購入の復元・購入の分析に RevenueCat（RevenueCat プライバシーポリシー）を利用します。これらで扱われるのは、ストアが発行する匿名の識別子・購入トークン等の購入履歴情報のみで、氏名・連絡先等の個人情報を開発者が取得することはありません。購入履歴は、アプリ機能の提供および購入の分析のために収集・処理されます。

第三者サービス（RevenueCat）

本アプリは広告・アナリティクス・トラッキング目的の SDK を一切組み込んでいません。RevenueCat SDK は App 内課金の購入状態確認・購入の復元・エンタイトルメント管理の目的でのみ利用しています。

開発者は、ユーザーの氏名・メールアドレス・学習内容などの個人情報を収集しません。一方で、RevenueCat の仕組み上、匿名のアプリ利用者識別子（RevenueCat が自動生成する App User ID）、購入情報、レシート情報等が RevenueCat 側で処理される場合があります。これらは購入の確認・復元・不正防止のためにのみ使用され、広告配信や解析、ユーザー追跡の目的には使用されません。

App Store Connect の App プライバシーでは、購入処理に伴う情報（Purchases / Purchase History）、AI所見をユーザーが実行した場合に送信されるユーザーコンテンツ（答案本文・テーマ名）、およびアプリの利用状況（製品の操作）を、いずれも「ユーザーに関連付けられないデータ」として申告しています。

記述対策（問題Ⅲ）で入力した答案の扱い

記述対策の機能でユーザーが入力した答案本文・テーマ名・指定用語・受験日は、端末内（UserDefaults / SharedPreferences）にのみ保存されます。下記「AI所見」をユーザーが自ら実行した場合を除き、これらが開発者や第三者に送信されることはありません。アプリを削除すると同時に削除されます。

文字数のカウント、「」で囲まれた語の抽出と個数の判定、空白や記号の連続の検出、14観点の計測は、すべて端末内で完結する処理です。これらの機械計測に生成AI・大規模言語モデル（LLM）は使用しておらず、インターネット通信も行いません。

なお、本アプリは試験実施団体が公表している出題テーマ・設問文・指定用語リストを収録していません。公式サイトへのリンクを設置し、ユーザーご自身が入力した用語と照合する方式としています。

AI所見（回数券・任意機能）における答案の送信

「AI所見」は消費型の回数券（10回パック・¥3,000）で利用する任意機能で、ユーザーがその都度表示される同意ダイアログで「同意して送信」を選択した場合にのみ動作します。回数券は失効せず、所見が正常に届いた時にのみ1回分を使用します。残高は匿名の識別子（ランダムな英数字。個人情報を含まず、ユーザーの特定はできません）に紐づけて開発者のサーバーで管理します。同意すると、答案本文・テーマ名・端末内計測の結果が、開発者の管理する中継サーバー（Cloudflare Workers）を経由して Anthropic 社の Claude API に送信され、所見（テーマとの一致・設問①と②の対応に関する参考コメント）の生成にのみ使用されます。

送信された答案本文は、中継サーバーには保存されず、ログにも記録されません。Anthropic 社による API 入力データの取り扱いは同社のプライバシーポリシー（anthropic.com/legal/privacy）に従います（既定で学習目的に使用されません）。所見の結果はお使いの端末内にのみ保存されます。

AI所見を一度も使わなくても、記述対策のその他すべての機能（字数・用語チェック、14観点の計測）は端末内のみで無料で利用できます。

利用状況データ（匿名）

アプリの改善のため、機能の利用状況を示すイベントの名前と回数だけ（例：「計測画面を開いた: 2回」「テンプレートを挿入した: 1回」「演習を始めた」「購入画面を表示した」）を、開発者の管理するサーバー（Cloudflare Workers）に送信し、日別の合計値として集計しています。無料体験から購入案内までの各段階（演習の開始・5問の解答・無料体験の上限到達・購入画面の表示・購入の完了）については、1つのインストールにつき各1回だけ送信し、到達した人数の把握のみに使用します。

送信されるデータに、答案の本文・テーマ名・入力した用語・解答の内容・端末やユーザーの識別子は一切含まれません。識別子がないため、特定のユーザーや端末をまたいだ追跡・分析は構造的にできません。集計値は90日で自動削除されます。この収集は機能の改善のためだけに使用され、広告や第三者提供には使用されません。

通知

ユーザーが受験日を入力した場合にのみ、通知の許可をお尋ねします（アプリ起動時には求めません）。予約されるのは次の2件のみで、いずれも端末内で完結するローカル通知です。プッシュ通知サーバーは使用していません。

1. 受験日の14日前（準備状況のお知らせ）
2. 2027年3月1日（合格発表日のお知らせ）

通知を許可しない場合でも、記述対策を含むアプリのすべての機能をご利用いただけます。通知はiOS/Androidの設定からいつでも無効にできます。

レビュー誘導

Apple 純正の SKStoreReviewController（App Store の標準レビュー機能）のみを使用しています。本アプリが個別にユーザーの評価情報を取得することはありません。

Privacy Policy (English)

This app does not collect any personal information, location data, or device identifiers. No network connections are made except for optional iCloud sync and Apple's standard In-App Purchase flow (managed via RevenueCat for entitlement tracking only). No third-party advertising or analytics SDKs are used. Study progress (answer history, accuracy, weak-question detection, bookmarks, cumulative attempt count) is stored only in the device's UserDefaults/SharedPreferences and the user's own iCloud account, and is removed when the app is uninstalled. The app uses department-scoped storage keys to manage per-discipline progress (e.g., kasen / road / steel) without cross-contamination. Text entered in the written-answer (Mondai III) practice feature — including the answer body, theme names, designated terms and the user's exam date — is stored only in the device's UserDefaults/SharedPreferences. All mechanical measurements (character counting, term extraction, the 14-point gauge) are performed entirely on-device with no network requests and no use of any large language model. The only exception is the optional Pro feature "AI Shoken" (AI commentary): when — and only when — the user explicitly taps "Agree and send" in a per-use consent dialog, the answer text, theme name and on-device measurement results are sent via the developer's relay server (Cloudflare Workers) to Anthropic's Claude API solely to generate reference commentary. The relay server does not store or log the answer text; Anthropic's handling of API inputs is governed by its own privacy policy (inputs are not used for training by default). The commentary result is stored only on the user's device. This feature has a daily usage cap and is never triggered automatically. For product improvement, anonymous usage counts of the written-answer feature (event names and counts only — e.g., "gauge opened: 2") are sent to the developer's relay server and aggregated as daily totals; these contain no answer text, no user or device identifiers, cannot be linked to any individual, and are automatically deleted after 90 days. Local notifications (two at most: 14 days before the user's exam date, and on the result announcement date) are scheduled only after the user enters an exam date and grants permission; no push notification server is involved.
